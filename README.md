# AeroGrid 4.0 — Вітрова електростанція з моніторингом швидкості вітру

Мобільний застосунок на Android для диспетчерського SCADA-моніторингу вітрової електростанції з потоковою обробкою телеметрії (Coroutines/Flow), інтерактивною геопросторовою візуалізацією та GPS-моніторингом, багаторівневою фільтрацією, REST API і локальною БД Room. Послідовне продовження проєктів ЛР №1–3.

## Загальна інформація

* **Дисципліна:** Розробка програмного забезпечення мобільних пристроїв
* **Університет:** Національний технічний університет України «Київський політехнічний інститут імені Ігоря Сікорського»
* **Кафедра:** Кафедра інженерії програмного забезпечення в енергетиці
* **Практична робота:** №4 (практичні заняття №13–16)
* **Варіант:** №2 — «Вітрова електростанція з моніторингом швидкості вітру»

## Нові можливості ЛР №4 (ПЗ №13–16)

### ПЗ №13 — Kotlin Coroutines та Flow у потоковій телеметрії
* `WindTelemetryFlowEngine` та оновлений `WindTelemetryViewModel`:
  * «холодні» потоки (`flow { ... }`) для давача швидкості вітру та прогнозної NWP-моделі;
  * трансформація даних оператором `map` через фізичну криву вітропарку (`WindParkModel`);
  * динамічна фільтрація порогу генерації (`filter`) зі згладжуванням введення користувача через `debounce(250 мс)`;
  * комбінування асинхронних потоків оператором `combine` та попарне калібрування через `zip`;
  * відмовостійкість потоку через автоматичне відновлення `retryWhen` (до 3 спроб) і перехоплення `catch`;
  * «гарячі» широкомовні потоки `SharedFlow` (`shareIn` та `MutableSharedFlow`) для подій SCADA в реальному часі.

### ПЗ №14 — Динамічний список (`LazyColumn`), картки та екран деталей
* `StationsMapScreen`: інтерактивний список енергетичних об'єктів України у `LazyColumn` (`Card` із типом, статусом, потужністю, швидкістю вітру, GPS-відстанню й описом), обробка порожнього стану `EmptyState` зі скиданням фільтрів.
* `StationDetailScreen` (`station_detail/{stationId}`): окремий екран детальної інформації про обрану ВЕС (поточна віддача, КВВП, кількість турбін, координати WGS-84, GPS-відстань і перехід до інженерних розрахунків).

### ПЗ №15 — Багаторівнева фільтрація, сортування та пошук
* Пошук у реальному часі (з `debounce`) за назвою станції, областю чи описом.
* Багаторівнева фільтрація через `Flow combine` + `derivedStateOf`: за типом ВЕС (`Наземна ВЕС`, `Прибережна ВЕС`, `Гібрид ВЕС+АКБ`), статусом (`Активна`, `Пікове навантаження`, `Обслуговування`) та порогом потужності (`Усі МВт`, `≥ 100`, `≥ 150`, `≥ 200 МВт`).
* Сортування за 7 критеріями, зокрема за назвою, типом, потужністю, вітром, датою оновлення та GPS-відстанню.

### ПЗ №16 — GPS-геолокація та інтерактивна карта ВЕС
* `AndroidLocationTracker`: отримання координат користувача через системний `LocationManager` (`GPS_PROVIDER`, `NETWORK_PROVIDER`, `FUSED_PROVIDER`) з потоковою підпискою `callbackFlow`, runtime-запитом дозволів `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` та резервним режимом при відмові доступу.
* `WindGeoMapPanel`: двостороння синхронізація списку `LazyColumn` і маркерів на карті (`animateScrollToItem` при виборі маркера + фокусування камери карти при виборі картки), спливаючі вікна `InfoWindow`, розрахунок відстані за формулою Гаверсінуса.
* Підтримка живої карти OpenStreetMap (`osmdroid`) без потреби у платному API-ключі та автономного векторного SCADA-радара України (`Canvas`).

## Збережена функціональність ЛР №1–3
* Моніторинг із Canvas-турбіною, Парк турбін (CRUD), Калькулятор Беца, Прогноз ВЕС із `Repository`/`DataSource` та REST API (`Retrofit2` + `Gson` + `MockWindBackendInterceptor`), JWT-автентифікація з `Preferences DataStore` і RBAC (`ADMIN`/`USER`), обробка помилок і журнал `error_log.txt`, єдина локальна БД Room v4 із 9 реальними ВЕС України (доступна через `🗄 БД` у верхній панелі та кнопку на головному екрані).
